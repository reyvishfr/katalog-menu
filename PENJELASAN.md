# Penjelasan Konsep React - Katalog Menu Kedai Bakar & Seduh

## 1. Daftar Komponen dan Fungsinya

Aplikasi katalog menu **Kedai Bakar & Seduh** dibangun dengan memecah antarmuka pengguna menjadi 8 komponen terpisah di dalam folder `src/components/` yang diatur oleh komponen induk `App.jsx`. Komponen **`Navbar`** berfungsi menampilkan logo/identitas kedai, tombol navigasi tab (`Beranda`, `Menu`, `Keranjang`), serta lencana (*badge*) jumlah item di keranjang yang selalu menempel (*sticky*) di bagian atas layar. Komponen **`SearchFilter`** menyediakan kontrol interaktif berupa filter cepat kategori berbasis *pill button*, kolom input pencarian nama menu, dropdown kategori, dan dropdown pengurutan harga. Komponen **`MenuList`** bertugas menerima daftar menu yang sudah disaring lalu menampilkannya dalam susunan grid kartu menu responsif atau menampilkan pesan kosong bila tidak ada menu yang cocok. Komponen **`MenuCard`** menampilkan informasi tiap menu secara individual meliputi emoji visual, nama, kategori, harga, lencana status populer/habis, tombol favorit (like), tombol tambah ke keranjang dengan feedback visual langsung, serta tombol pembuka detail. Komponen **`MenuDetail`** menampilkan informasi lengkap berupa deskripsi menu, kategori, status ketersediaan, dan harga di dalam kartu yang sedang dibuka. Komponen **`Cart`** menampilkan daftar pesanan di keranjang lengkap dengan kontrol penambah/pengurang jumlah porsi, subtotal per menu, tombol hapus, serta total keseluruhan harga. Komponen **`Button`** merupakan komponen tombol *reusable* yang mendukung variasi tampilan (`primary`, `secondary`, `danger`, `action-pill`) dan status `disabled` untuk dipakai ulang di berbagai komponen. Terakhir, komponen **`Footer`** menampilkan penutup di bagian bawah halaman lengkap dengan identitas mahasiswa (nama, NIM, program studi, dan tahun pembuatan).

## 2. Penggunaan Props

Konsep *props* (properties) digunakan sebagai jalur komunikasi satu arah (*one-way data flow*) untuk mengalirkan data maupun fungsi *event handler* dari komponen induk (`App.jsx`) ke komponen-komponen anak (*child components*). Misalnya, `App.jsx` mengirimkan nilai jumlah total item keranjang melalui prop `jumlahKeranjang` ke komponen `Navbar`, serta mengirimkan state pencarian dan fungsi pengubahnya (`keyword`, `onKeywordChange`, `kategoriAktif`, `onKategoriChange`, `urutan`, `onUrutanChange`) ke komponen `SearchFilter`. Daftar menu hasil penyaringan dikirimkan lewat prop `daftarMenu` ke `MenuList`, yang kemudian meneruskan setiap objek menu beserta fungsi handler (`menu`, `isFavorit`, `onToggleFavorit`, `onTambahKeranjang`, `onToggleDetail`, `detailTerbuka`) ke masing-masing `MenuCard`, lalu diteruskan lagi ke `MenuDetail` dan `Button`. Demikian pula pada bagian keranjang, `App.jsx` menggabungkan data item keranjang dengan detail menu lalu mengirimkannya melalui prop `isiKeranjang`, `total`, serta fungsi `onTambahJumlah`, `onKurangJumlah`, dan `onHapus` ke komponen `Cart`.

## 3. Penggunaan State (`useState`)

Seluruh data dinamis yang dapat berubah karena interaksi pengguna dikelola secara terpusat di komponen `App.jsx` menggunakan React Hook `useState`. Terdapat enam state utama yang digunakan, yaitu `keyword` (bertipe string untuk menyimpan kata kunci pencarian nama menu), `kategoriAktif` (bertipe string dengan nilai awal `"Semua"` untuk menyaring kategori Makanan, Minuman, atau Snack), dan `urutan` (bertipe string dengan nilai `"default"`, `"termurah"`, atau `"termahal"` untuk mengatur urutan harga). Selain itu, terdapat state `favorit` (array berisi ID menu yang ditandai suka oleh pengguna), `keranjang` (array berisi objek `{ id, jumlah }` yang mencatat pesanan beserta jumlah porsinya), serta `detailTerbuka` (menyimpan ID menu yang panel detailnya sedang ditampilkan, atau bernilai `null` jika tidak ada detail yang dibuka). Daftar menu yang tampil di layar dan total harga keranjang tidak disimpan di state terpisah, melainkan dihitung secara langsung (*derived state*) setiap kali salah satu state utama tersebut mengalami perubahan.

## 4. Penggunaan Event Handling

*Event handling* di aplikasi ini menangani berbagai aksi pengguna seperti klik tombol (`onClick`) dan perubahan nilai input formulir (`onChange`). Pada komponen `SearchFilter`, event `onChange` dipasang pada elemen `<input>` pencarian dan kedua elemen `<select>` (kategori dan urutan) untuk menangkap nilai terbaru dari `e.target.value` lalu memperbarui state di `App.jsx`. Pada komponen `MenuCard` dan `Button`, event `onClick` digunakan untuk memicu fungsi `handleToggleFavorit` saat pengguna menekan ikon hati, `handleTambahKeranjang` saat pengguna menambahkan menu ke keranjang, serta `handleToggleDetail` untuk membuka atau menutup rincian menu. Di dalam komponen `Cart`, event `onClick` pada tombol `-`, `+`, dan `Hapus` memanggil fungsi `handleKurangJumlah`, `handleTambahJumlah`, serta `handleHapusKeranjang` yang memperbarui isi state `keranjang` secara imutabel menggunakan metode array seperti `map()` dan `filter()`.

## 5. Conditional Rendering

Konsep *conditional rendering* diterapkan di berbagai komponen untuk menyesuaikan tampilan antarmuka berdasarkan kondisi state atau data menu saat itu. Pada `MenuList`, jika panjang array `daftarMenu` adalah nol, komponen akan menampilkan pesan *"Menu tidak ditemukan"* alih-alih merender grid kartu menu; begitu juga pada `Cart` yang menampilkan pesan *"Keranjang masih kosong"* apabila belum ada item yang ditambahkan. Di dalam `MenuCard`, operator logika `&&` dan *ternary operator* (`? :`) digunakan untuk menampilkan badge *"★ Populer"* hanya jika properti `menu.populer` bernilai `true`, menampilkan badge *"Habis"* dan menonaktifkan (`disabled`) tombol Tambah jika `menu.tersedia` bernilai `false`, mengubah ikon tombol favorit antara `❤️` dan `🤍`, serta merender komponen `<MenuDetail />` hanya ketika `detailTerbuka === menu.id`. Selain itu, pada komponen `Cart`, tombol pengurang jumlah porsi (`-`) juga diberikan kondisi `disabled={item.jumlah <= 1}` agar jumlah porsi tidak turun di bawah 1.

## 6. List Rendering

*List rendering* digunakan untuk menampilkan kumpulan data array menjadi deretan elemen JSX secara dinamis menggunakan metode `.map()`. Penerapan utamanya terdapat pada komponen `MenuList`, di mana array `daftarMenu` dipetakan menggunakan `daftarMenu.map((menu) => <MenuCard key={menu.id} ... />)` untuk menghasilkan kartu-kartu menu sesuai hasil pencarian dan filter. Penerapan kedua terdapat pada komponen `Cart`, di mana array `isiKeranjang` dipetakan menggunakan `isiKeranjang.map((item) => ...)` untuk menampilkan setiap baris pesanan beserta perhitungan subtotalnya. Pada kedua proses *list rendering* tersebut, setiap elemen anak selalu diberikan atribut `key` berupa ID unik dari data menu (`key={menu.id}` dan `key={item.id}`), bukan indeks array, sehingga React dapat mengenali setiap item secara akurat dan memperbarui DOM secara efisien tanpa memunculkan peringatan di konsol.
